# Aamir Shaikh — Engineering Portfolio

A unique, editorial, and high-performance developer portfolio built with **React**, **Tailwind CSS**, and **Vite**, crafted strictly according to the **Caregiver** brand identity archetype (warm, composed, bold, timeless, and nurturing).

---

## 🎨 Visual Identity & Brand System

- **Brand Primary Accent**: Crimson Red (`#B3261E`)
- **Secondary Surface**: Warm Stone Cream (`#E6E1D2` / `#F4F0E6`)
- **Background**: Editorial Off-White (`#F9F7F1`)
- **Text & Contrasts**: Charcoal (`#1B1A17`), Olive Slate (`#6F6B5F`), Border Tan (`#C9C4B3`)
- **Typography**: Georgia serif display paired with clean monospaced tokens (`JetBrains Mono`)
- **Accessibility**: 100% WCAG 2.1 compliance with high contrast ratios
- **Motion Scale**: Composed 250ms–600ms responsive transitions
